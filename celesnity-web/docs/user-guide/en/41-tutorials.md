# In-app guided tutorials

Besides this manual, Celesnity ships **guided tutorials** that run inside the app: each step highlights the exact control to use and waits until you have done it before moving on. They are the fastest way to learn a business flow.

## 1. Opening the tutorial list

- Click the **Tutorials** button in the bottom-right corner of any screen, or
- Open the **Guide** module (under *Resources*), which also holds reference chapters: Overview, Database, Sources, Metadata scan, Pipelines, Runs, Tables and snapshots.

On your first sign-in the app also invites you with the **"Learn the workspace as you go"** card.

## 2. Starting a tutorial

1. In **Guided tutorials**, pick one.
2. The detail page shows **Before you start** (prerequisites) and **Choose tutorial context** (which database or sample data to practise on).
3. Click **Start tutorial**.

## 3. During a tutorial

- The **Step X of Y** bar shows your progress.
- The control you are asked to use is **highlighted**; the rest of the screen still works normally.
- **Next** moves on, **Previous** goes back, **Pause** stops for now (progress is saved and resumes when you return), **Finish** ends the last step.
- On completion you see **Tutorial complete**; **Repeat tutorial** runs it again.

## 4. Available tutorials

| Tutorial | What you learn | Requires |
| --- | --- | --- |
| **Create a database and discover source schema** | Create a database, connect a source, test it, assign a metadata scan, browse the discovered tables. | Databases, Crawler, Source schema |
| **Run your first SQL query** | Open Query, run a SELECT, read the result. | Query |
| **Ask your connected data** | Pick the sample data, ask the assistant, view its reasoning, open the result table. | Home |
| **Create artifacts from data** | Produce a table, a chart and a report from one question and open each on the side panel. | Home |
| **Clarify and approve an action** | Answer the assistant's clarifying question and approve an action (saving a report). | Home |
| **Work with files and conversations** | Attach the sample CSV/XLSX, start a new conversation, switch between conversations. | Home |

The four assistant tutorials run in a **sandbox with fictional data** ("Fictional data · no Agent or workspace writes"): practise freely without touching real data.

## 5. When a tutorial is missing

A tutorial appears only when your groups include every module in its "Requires" column. Ask for access as described in *Roles and access*.
