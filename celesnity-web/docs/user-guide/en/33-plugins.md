# Plugins and Google Drive

The **Plugins** module (under *Tools*) lists the external apps the AI assistant can sign in to and work with on your behalf. Today that is **Google Drive**: once you connect it, the assistant can read files in your Drive and create new ones when you ask.

## 1. Connecting Google Drive

1. Open **Plugins**. The **Google Drive** row shows **Needs sign-in** until it is connected.
2. Click **Sign in**. A Google window opens: pick the account and accept the permissions Celesnity asks for.
3. When Google confirms, you return to the Plugins page; the account appears under **Connected accounts**.
4. To add another account (a team drive, for example), click **Connect another account**.

A connection is **yours alone**: colleagues cannot reach your Drive through the assistant.

## 2. Using Google Drive in a conversation

1. Go to **Home**, type **@** in the question box and choose **Google Drive**.
2. Say what you need, for example: *"@Google Drive find the Q4 plan and summarise the budget section"*, or *"@Google Drive create this week's report file from the numbers we just calculated"*.
3. The assistant lists or reads the files, then answers. When it creates a file it tells you the name and location.

You can also ask *"is there anything about contracts in my Drive?"* without typing @; the assistant uses the plugin when it fits.

## 3. What the assistant may and may not do

| May | May not |
| --- | --- |
| List folders and files | Edit an existing file |
| Read file contents | Delete a file |
| Create new files | Share a file with others |

These limits are fixed so that your files are never changed unexpectedly.

## 4. Disconnecting

Under **Connected accounts**, click **Disconnect** next to the account. The assistant loses access to that Drive immediately. You can also revoke access from your Google account's security page.

## 5. Common problems

| You see | What to do |
| --- | --- |
| Google sign-in finished but the row still says *Needs sign-in* | Reload the Plugins page. If it persists, the Google window may have been blocked; allow pop-ups and try again. |
| The assistant cannot find a file | Check the file name and that the connected account is the one that holds the file. |
| A sign-in-expired error | Click **Disconnect**, then **Sign in** again. |
