# Documents

The **Documents** module (under *Resources*) is the store of PDFs and reports the AI assistant can read and cite. Upload contracts, procedures, reports… then ask the assistant about their contents; reports the assistant writes are stored here too.

## 1. Uploading a document

1. Open **Documents**.
2. Click **Upload PDF** or drag a file onto the upload area.
3. Limits: **PDF only**, at most **20 MB** and **200 pages** per file.
4. The file appears in the table with its processing status.

## 2. The document table

| Column | Meaning |
| --- | --- |
| **Filename** | The file name. |
| **Pages** | Page count. |
| **Status** | **Extracted**: text was found and the assistant can read it. **No text**: the file is a scanned image without a text layer; the assistant will say plainly that it cannot read the content. |
| **Uploaded** | When it was uploaded. |

Click a row to see the extracted text and check what the assistant "sees".

## 3. Using documents in a conversation

- Ask directly in **Home**: *"What are the payment terms in the ABC contract?"* The assistant searches the store and answers with **Sources** pointing at the file and page.
- Or attach while asking: **+ → Attach a file** in the question box. An attached file is stored in Documents as well.

## 4. Reports written by the assistant

When you ask the assistant to *"write a report… and save it"* (in Home or in an Automation), it creates a document that may contain charts. It appears here; open it to read, and **Download PDF** when you need to send it on.

## 5. Scans without text

**No text** is typical for scans. Run the file through OCR software to produce a PDF with a text layer, then upload it again. The old file can stay or be removed.

## 6. Notes

- Everyone with access to the Documents module sees the organization's documents; do not upload files that may not be shared internally.
- The assistant only cites documents that were uploaded; it never invents a page or a file.
